# Downlism v0.7.1

本版將 0.7.0 本機測試版的改動整理發布，另外修正歷史紀錄測試清理 SQLite 連線池的偶發失敗。應用程式與安裝程式為 0.7.1，瀏覽器擴充功能維持 0.2.0。

## 更新注意

- 安裝後，在 Chrome／Edge 重新載入 Downlism 擴充功能，並重新整理已開啟的網頁。
- 舊版未綁定來源的 HTTP 續傳紀錄不會直接沿用，未完成下載可能從頭開始。完成檔案不會被刪除。
- 自動接手只處理已觀察到 GET 回應、且瀏覽器確認為下載的項目。MEGA、POST、XHR、blob 與不確定的來源留給瀏覽器。
- 安裝檔未簽章，SmartScreen 可能警告。新安裝不再自動啟用開機自啟，可自行到設定開啟。

## 自訂與操作

- 獨立設定視窗：下載資料夾、連線、同時下載數、限速、HTTP 逾時、重試、分類規則。
- 主題、系統匣、剪貼簿提示、接手確認、進度視窗、通知、啟動續傳及重複網址防護。
- 設定 JSON 匯入／匯出與還原預設值。
- 搜尋、排序、多選操作、批次新增，及 TXT 網址清單匯入／匯出。
- 個別 HTTP 下載的連線、限速及 SHA-256 校驗。
- 擴充功能的副檔名、排除網站、限定網站和影片偵測設定。

## 可靠性修正

- 修正分段續傳紀錄共用緩衝區的競態，檢查回應範圍與實收長度。
- 續傳紀錄綁定來源網址與驗證碼，拒絕重疊／越界紀錄及不安全重新導向；Cookie 不跨來源轉送。
- 同時下載數改用可調整的 FIFO gate；修正重複繼續、全部暫停和移除後項目復活。
- 保存真正檔名、資料夾與下載選項，修正舊設定的缺欄位預設值。
- 合併 UI 更新、縮小 HTTP／雜湊緩衝區，限制 `.torrent` 中繼資料大小。

## 驗證與限制

發布建置會執行 177 項 C# 測試、34 項擴充功能測試及 TypeScript 型別檢查，再產生兩種 runtime 版型的單一安裝程式。先前的 0.7.0 UI 測試已驗證設定、批次操作、暫停續傳、8 MiB 檔案 SHA-256 與重開還原；該次 working set 取樣為 201.5 MiB，不代表低 RAM 目標已完成。

尚未完成排程、全域即時限速、代理與網站登入設定、多鏡像、完整同名 partial 隔離、Torrent 檔案選取、Firefox、簽章及自動更新。真實 MEGA／登入網站、長時間壓力與乾淨 VM 安裝測試仍待補齊。完整清單與先前測試紀錄見 [0.7.0 本機驗證紀錄](release-0.7.0.md)。

## 下載與重建

Release 附件：`Downlism.Setup.exe`、`SHA256SUMS.txt`。校驗碼以同一 Release 的 `SHA256SUMS.txt` 為準。

```powershell
pwsh -File scripts/Publish-Installer.ps1 -Version 0.7.1
```

本機產物：`artifacts/installer/Downlism.Setup.exe`。建置紀錄：`artifacts/publish-0.7.1.log`。
