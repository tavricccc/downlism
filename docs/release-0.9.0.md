# Downlism 0.9.0

- 主清單與獨立進度視窗：下載中顯示即時速度，完成後切換為平均速度。
- 即時速度取最近 2 秒新增的位元組，每 250 毫秒更新。沒有新資料時，舊速度會在取樣視窗過期後降到 0，不再停留在先前數值。
- 暫停、排隊、等待重試與失敗時顯示「—」。續傳會重新建立即時速度基準，不把已存在的檔案資料當成新流量。
- 完成後的平均速度仍會保存並在重開後還原。主清單欄位改名為「速度」，提示說明目前顯示的是即時或平均速度。
- 保留一般字重、小型欄位名稱與完成後的滿格原生進度條。
